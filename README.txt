DYMKA STUDIO — demo portfolio website

FILES
- index.html: page structure and copy
- style.css: responsive styling
- script.js: mobile navigation and current year

PREVIEW LOCALLY
Open index.html in a modern browser. An internet connection is needed for the Google Fonts; the site otherwise works without a build step.

PUBLISH FREE WITH CLOUDFLARE PAGES (DIRECT UPLOAD)
1. Open https://dash.cloudflare.com/ and sign in or create a free account.
2. Open Workers & Pages, then choose Create application / Pages (the UI wording may vary).
3. Choose the option to upload static assets / Direct Upload.
4. Give the project a name such as dymka-studio-demo.
5. Upload the contents of this folder (index.html, style.css, script.js) or upload the ZIP if the page accepts ZIP.
6. Deploy. Cloudflare should provide a public *.pages.dev URL.
